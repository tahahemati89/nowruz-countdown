# 🌱 Nowruz Countdown

### A simple, elegant countdown to the Persian New Year.

Count down the days, hours, minutes, and seconds until **Nowruz 2027** — the beginning of the Persian New Year.

---

## ✨ Overview

**Nowruz Countdown** is a responsive countdown timer built with HTML, Tailwind CSS, and Vanilla JavaScript.

This project was created to practice JavaScript fundamentals by combining date calculations, DOM manipulation, and timed execution in a real-world project.

## 🚀 Features

- ⏳ Real-time countdown to Nowruz 2027
- 📅 Displays days, hours, minutes, and seconds
- 🔢 Two-digit formatting for single-digit values
- ⚡ Automatically updates every second
- 🎨 Clean and minimal user interface
- 📱 Designed to work across different screen sizes

## 🛠️ Built With

- **HTML5** — Page structure
- **Tailwind CSS** — Styling and layout
- **JavaScript (ES6+)** — Countdown logic and DOM updates

## 🧠 What I Learned

While building this project, I practiced:

- Working with the JavaScript `Date` object
- Calculating time differences in milliseconds
- Using `Math.floor()` and the modulo operator (`%`)
- Breaking a problem into smaller calculation steps
- Manipulating the DOM with `querySelector()` and `textContent`
- Formatting numbers with `toString()` and `padStart()`
- Using functions and `setInterval()` to update the interface automatically

## ⚙️ How It Works

1. The target date and current time are compared.
2. The time difference is converted from milliseconds into seconds, minutes, hours, and days.
3. The remaining time for each unit is calculated.
4. The results are displayed in the corresponding HTML elements.
5. The countdown updates every second.
